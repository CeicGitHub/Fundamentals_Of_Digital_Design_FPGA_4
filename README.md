# Fundamentals_Of_Digital_Design_FPGA_4
This Module4 is about programming in SystemVerilog, using the DE2-115 board with Cyclone IV EP4CE115F29C7N microcontroller, use sequential and combinational logic programming. The implementation of testbenches using ModelSim Altera. We learned about use a procedural system blocks and typedef enums,and the internal system clock that is 50MHz.
